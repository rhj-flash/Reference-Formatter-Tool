## ✨ 功能特点

### 🎯 核心功能
- **智能文献分割** - 自动识别和分割多个文献条目
- **格式统一** - 统一调整中英文字体、字号和间距
- **Word 兼容** - 完美支持 Microsoft Word 文档导出
- **批量处理** - 支持同时处理多篇文献引用

### 🎨 界面特点
- 现代化 UI 设计
- 实时预览效果
- 简洁直观的操作流程
- 响应式布局，适配不同分辨率

## 📥 下载安装

### 方法一：直接下载可执行文件
前往 [Release 页面](https://github.com/rhj-flash/Reference-Formatter-Tool/releases) 下载最新版本的 `ReferenceFormatter.exe`

### 方法二：从源码运行
```bash
# 克隆仓库
git clone https://github.com/rhj-flash/Reference-Formatter-Tool.git
cd Reference-Formatter-Tool

# 安装依赖
pip install -r requirements.txt

# 运行程序
python main.py
```

## 🚀 快速开始
1. 打开软件
2. 粘贴或导入文献引用
3. 调整格式设置
4. 导出为 Word 文档
